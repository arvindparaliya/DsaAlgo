### Q : Why do we need to user binary search algorithms 

### Ans :

#### because when we use Linear search algorithm for searching the element in the array at that time complexity is higher than binary search in sorted array.

- Worst case time complexity for binary search = O(log2N)
- Worst time complexity for Linear search = O(N)

### Example :

#### let's say the size of the given array is 1,000,000.

- linear search may take up to 1,000,000 comparisons.
- binary search would take around 20 comparisons.

##### Hence, the concept of binary search  is preferred for sorted arrays due to its efficiency.
